# 🃏 短牌竞技场 · AI 与真人的牌桌

基于 PySide6 的短牌德州扑克桌面应用：让两个 LLM 对战、观看离线机器人演示，或亲自挑战 AI。支持 OpenAI 兼容 API，可选独立 AI 解说员。

## 开始使用

需要 Python 3.12+，推荐使用 [uv](https://docs.astral.sh/uv/)：

```bash
git clone https://github.com/usermbzlj/ai-shortdeck-poker.git
cd ai-shortdeck-poker
uv sync
uv run python main.py
```

无需密钥也能使用：欢迎页点「先看一场演示」，或「我来挑战 AI」并将对手设为「内置机器人」。演示不会覆盖已保存的配置。

## 配置选手

「设置」中分别选择 A / B 的厂商、模型和显示名称。预设包括 DeepSeek、OpenAI、豆包、GLM、Kimi、通义、OpenRouter、Ollama 和自定义兼容接口；支持后台拉取模型列表和测试连接。

可设置温度、thinking 参数发送策略、思考预算和选手人设。解说员可单独配置、跟随 A，或留空关闭。设置保存在项目根目录的 `.env`，原有键保持兼容；请勿分享或提交包含密钥的配置文件。

非法 AI 输出会重答，越界可自动夹值，最终用过牌／弃牌兜底；网络错误有退避重试、友好提示和连续失败保护。高级页可配置超时与重试上限。

## 观赛与导演

- **观赛**：自绘牌桌、四色牌、筹码、胜率、喊话气泡和统一直播时间线，可筛选动作、推理、喊话与解说。
- **导演**：额外提供比赛设置、指定牌面、手动操作、快捷下注和原始日志。
- 顶部控制开始、真正暂停、单步与下一手；节奏支持慢／标准／快／极速，内置机器人也有可见思考时间。
- 外观设置支持减少动画、四色牌和胜率开关；窗口布局、模式、节奏等会自动记忆。

## 赛制与离线演示

支持打到输光、固定手数、每 N 手盲注 ×1.5。可选择交换座位复赛：按同一套牌序换座重打，并展示两场合计结果。总结包含统计、筹码曲线与风格各异的感言。

内置紧凶、松凶、跟注站三种机器人，不发网络请求，可与 AI、其他机器人或真人对战。

## 人机对战

将一个座位的厂商设为「真人（我来打）」，另一位选择 AI 或内置机器人；目前只允许一个真人座位。

真人固定显示在牌桌下方。你的回合自动对局会等待，不限时；用发光操作栏弃牌、过牌／跟注、下注／加注，滑条、数字框与快捷筹码支持合法范围内的目标总额。可选喊话会随动作发送给对手，并出现在气泡和时间线。

默认隐藏 AI 底牌至摊牌，隐藏胜率与进行中的 AI 内心 OS；本手结束后以「本手揭晓」补充推理。人机局解说在摊牌前只接收公开信息。导演模式的「上帝视角」可主动解除显示隐私；开启后不再是公平挑战。原始日志在隐私模式进行中不可见。

## 数据、牌谱与导出

「数据」页显示可点击复盘的筹码曲线，以及 VPIP、PFR、3bet、AF、WTSD、W$SD、平均思考、非法输出率和兜底次数。全押 EV 在跟注全押时计算：翻牌前固定抽样 2000 次，翻牌后精确枚举；“运气 vs 实力”仅作 EV 参考，并非真实实力评估。

「牌谱」可按比赛筛选或搜索选手、牌面、推理、标记，复盘支持前后步进与播放，同时展示当时的推理、喊话和解说。自动标记包括 ≥20BB 大底池、翻牌后高牌诈唬成功、≥70% 全押优势被逆转、河牌一对及以下英雄跟注。

支持导出选中手牌或整场比赛：JSON、PokerStars 风格文本（best effort，非官方导入保证）、以及复用牌桌渲染的分享 PNG；多手分享图按手牌分别保存。

牌谱在每手结束时写入项目目录的 **`data/history.sqlite3`**，包含真人和 AI 的完整牌谱，但不保存 API Key。数据与密钥配置均已 gitignore。可通过 `SHORTDECK_DATA_DIR` 指定其他数据目录。导出的牌谱包含底牌与推理，请自行决定是否分享。

## 快捷键

| 按键 | 操作 |
|---|---|
| F | 弃牌 |
| C | 过牌或跟注 |
| R | 按当前金额下注／加注 |
| A | 全下 |
| Space | 开始／暂停 |
| N | 单步 |

真人回合在观赛与导演模式都可操作；非人机局的手动动作快捷键仅在导演模式生效。输入喊话、金额等文字时不会误触快捷动作。

## 规则与测试

36 张牌（6 至 A），同花大于葫芦，A-6-7-8-9 为最小顺子，单挑、小盲为庄家。仅用于技术实验与娱乐，不涉及真实货币。
